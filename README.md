# ISTA Safaris

Android app (Flutter) and Django API for ISTA Safaris, a travel companion for Tsavo and Taita Taveta, Kenya.

| Folder | Contents |
| --- | --- |
| `mobile/` | Flutter app, Android only |
| `backend/` | Django REST API and admin |
| `docs/` | Budget, progress log, third-party list |
| `reference/web/` | Web design reference (read only, not shipped) |

Start with [`CLAUDE.md`](CLAUDE.md) (the build note) and [`docs/PROGRESS.md`](docs/PROGRESS.md) (current state, decisions and how to run).
